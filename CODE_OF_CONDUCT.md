# Code of conduct

We want a respectful, technically honest community.

- Be courteous. Critique work, not people.
- Be accurate. Say what was measured, what was assumed and what was not checked. Correct mistakes openly.
- No harassment, discrimination or personal attacks.
- Respect other people's time: keep issues and pull requests focused.

Maintainers may edit or remove contributions that break these rules and may restrict participation
for repeated violations. Report concerns through a private GitHub channel to the repository owner.
This text is adapted in spirit from the Contributor Covenant but is not a copy of it.
