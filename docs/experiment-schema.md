# Experiment result schema

Every experiment writes `experiments/results/<experiment_id>.json`, validated against
[`experiments/schema/experiment_result.schema.json`](../experiments/schema/experiment_result.schema.json)
(JSON Schema 2020-12, 28 required fields).

| Group | Fields |
|---|---|
| Identity | `schema_version`, `experiment_id`, `title`, `notebook`, `algorithm`, `application`, `plant_model` |
| Data | `dataset` (`name`, `kind`, `description`), `experiment_type` |
| Configuration | `controller_parameters`, `plant_parameters`, `sampling_time_s`, `input_configuration`, `disturbance_configuration`, `operating_conditions`, `number_of_trials`, `random_seed` |
| Environment | `software_environment`, `hardware_configuration`, `firmware_version`, `execution_timestamp`, `reproducibility_instructions` |
| Outcome | `metrics`, `baseline`, `checks`, `limitations`, `result_status`, `figure_references` |

Allowed values:
- `dataset.kind`: `measured_experiment`, `public_dataset`, `simulated`, `synthetic_illustrative`, `none`.
- `experiment_type`: `software_simulation`, `controller_in_the_loop`, `hardware_in_the_loop`, `physical_hardware`.
- `result_status`: `completed`, `partial`, `failed`.

`scripts/validate_results.py` rejects a file that fails the schema, is not `completed`, has a failed
check, references a missing figure, or claims hardware. Derived files (`experiments/metadata/`,
`experiments/configurations/`, `experiments/index.json`) are regenerated by
`tools/build_experiment_index.py`.

Writing a result from code (a failed check downgrades `completed` to `partial` automatically):

```python
from control_lab.experiments import ExperimentRecord, check, save_figure

rec = ExperimentRecord(
    experiment_id="exp_x", title="...", notebook="notebooks/...", algorithm="...",
    application="...", plant_model="...",
    dataset={"name": "none", "kind": "simulated", "description": "..."},
    metrics={...}, checks=[check("closed form matches", abs(err) < 1e-6, f"{err:.2e}")],
    limitations=["..."],
)
rec.save()  # validates against the schema, then writes experiments/results/exp_x.json
```
